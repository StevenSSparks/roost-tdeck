# Contributing to RoostOS

Thanks for your interest! This is a hobbyist / community project under the **MIT license** — questions, bug reports, and pull requests are all welcome.

## Ask a question or report a bug
Open a [GitHub Issue](../../issues). Use the **Question** template to ask anything, or **Bug report** to flag a problem. Please include your hardware, what you did, and what happened.

## Contribute code
1. Fork the repo and create a branch.
2. Keep changes focused; match the surrounding code style.
3. Build/test locally (see the README for the toolchain).
4. Open a pull request describing the change and how you tested it.

We review PRs as time allows — no guarantees, but good ideas are very welcome. By contributing you agree your work is licensed under the project's MIT license.

## Be kind
Be respectful and constructive. That's it.
